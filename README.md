# 📊 Power BI Final Project

## 📌 Description
This repository contains practices and a final project developed in Power BI as part of a certification course focused on data analysis and business intelligence.

The project includes data cleaning, transformation, modeling, KPI creation, and interactive dashboards designed to support decision-making through data visualization.

## 🎯 Objectives
- Analyze and transform datasets
- Create interactive dashboards
- Develop KPIs and business metrics
- Apply data visualization best practices
- Generate insights for decision-making

- Excel / CSV datasets
